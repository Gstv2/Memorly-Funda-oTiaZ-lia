# Memorly - Fundação Tia Zélia

Memorly: Solução tecnológica para preservação de memória institucional e gestão autônoma de ONGs. Desenvolvido no curso de ADS do IFPI Campus Piripiri.

## Sobre o Projeto

Este projeto é um memorial digital da Fundação Tia Zélia, uma instituição dedicada a projetos sociais, culturais e esportivos.

## Como editar este código?

Você pode trabalhar localmente usando seu IDE de preferência.

O único requisito é ter Node.js e npm instalados.

### Passos para Desenvolvimento Local:

```sh
# 1. Clone o repositório
git clone <URL_DO_REPOSITORIO>

# 2. Navegue até o diretório do projeto
cd Memorly-Funda-oTiaZ-lia

# 3. Instale as dependências
npm install

# 4. Inicie o servidor de desenvolvimento
npm run dev
```

## Tecnologias Utilizadas

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Deploy

O projeto está configurado para ser implantado na Vercel ou plataformas similares. Certifique-se de configurar as variáveis de ambiente necessárias (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, etc.) nas configurações da plataforma de deploy.
