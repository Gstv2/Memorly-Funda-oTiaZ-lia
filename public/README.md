# Pasta Public - Fundação Tia Zélia

Esta pasta contém os ativos estáticos que são servidos diretamente pelo servidor sem processamento do Vite.

## Arquivos e suas Funções:

1.  **favicon.ico**:
    *   **O que é**: O ícone que aparece na aba do navegador.
    *   **Por que**: Essencial para a identidade visual da fundação e profissionalismo do site.

2.  **placeholder.svg**:
    *   **O que é**: Uma imagem vetorial genérica.
    *   **Por que**: Utilizada como imagem de fallback (reserva) caso algum projeto ou postagem do blog não possua uma imagem de capa carregada, garantindo que o layout nunca fique quebrado.

3.  **robots.txt**:
    *   **O que é**: Um arquivo de instrução para robôs de busca (como o do Google).
    *   **Por que**: Configurado para permitir a indexação de todas as páginas públicas da fundação, ajudando no SEO e na visibilidade orgânica do site.

---
*Nota: Todos os arquivos aqui são copiados para a raiz da pasta `dist` durante o processo de build.*
